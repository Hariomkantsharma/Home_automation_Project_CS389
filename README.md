# Home Automation Project CS389
This project focuses on automating and remotely controlling home appliances while also predicting power consumption using a machine learning model. We are developing an Android app using Java. The hardware used for automating the appliances is a Raspberry Pi 3 Model B, and Google Sheets is used for data collection.

This repository contains only the code for the Android app.
