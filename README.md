# Home_automation_Project_CS389
A project of automating and remote controlling of Home appliances, also predicting power consumption using ML model. Developing a Android App using Java for backend and XML for front end. Hardware used for automating appliances is Raspberry Pi 3 model B. Google sheet is used as database.

In this Repository only the android app code is stored.
